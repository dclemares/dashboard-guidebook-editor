# Dashboard · Guidebook editor (new blocks prototype)

Static prototype of the host-side guidebook editor in the Chekin dashboard. It works like today's editor: a Notion-style page where you add blocks with **+** or by typing **/**. The block menu keeps today's groups (Basic, Media, Embed) and adds a new **Highlights** group:

- **Info box**: label + value + optional Copy button (up to 6 rows per box).
- **Notice**: highlighted text with an icon, Warning (orange) or Info (blue) style.
- **Numbered steps**: step-by-step instructions, automatic numbering.
- **Colour list**: items with a colour, a title and a description (e.g. recycling bins).
- **Place list**: items with an icon, a title and a subtitle.
- **Button (CTA)**: text + destination (guest app section or external link).

The guest preview on the right updates as you type. All data is sample data; nothing is saved.
